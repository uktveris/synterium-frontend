# Frontend for cloud storage project
This repository contains code for the frontend UI components for cloud storage project. The backend code is contained in [this repository](https://github.com/uktveris/synterium-backend). This repository is only for educational purposes.

## Technology stack
This project uses the following technologies:

- MongoDB
- Express
- React
- Node

The frontend service manages UI changes, file upload and download, and user log in and register forms.

Development server can be run with npm run dev. As for production, it can be run with npm run start.
